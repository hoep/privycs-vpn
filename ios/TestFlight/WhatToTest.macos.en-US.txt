Native macOS app built from the iOS codebase (same screens as iPhone, in a Mac
window). WireGuard / AmneziaWG / OpenVPN / IPSec, pools + rotation, on-demand
network rules, backup/restore, gateway import.

v1.1.5.101 — Connect screen now shows the protocol pill even for single-protocol
connections (e.g. WireGuard-only), matching Android/Desktop. Previously the pill
row only appeared for multi-protocol connections.

NEW (recent builds):
- Real KILL SWITCH: with it ON, all traffic is forced through the tunnel and the
  system DROPS traffic when the tunnel is down / (re)connecting — no leak. LAN
  stays reachable.
- Cross-platform BACKUP now round-trips with iPhone/Android/Desktop (active
  protocol + last-connected time written in the shared format).

HOW TO TEST:
- Import a config (file or paste a gateway/QR link) and connect; try each protocol.
- Kill Switch ON → disconnect Wi-Fi/Ethernet briefly → traffic stays BLOCKED until
  the tunnel re-establishes; LAN still reachable.
- Create a pool and watch rotation; set an On-Demand rule and switch networks.
- Export a backup on Mac, restore it on iPhone/Android/Desktop (and vice-versa).

Known gaps (being polished): app icon may be generic; QR uses paste-input instead
of the camera; reading the current Wi-Fi name needs Location permission.
