v1.1.3.14 (build 84) — IPSec traffic counter.

Adds a live download/upload + speed graph for IPSec/IKEv2 connections (which
previously always showed 0 B, because Apple's built-in IKEv2 exposes no byte
API). We now read the tunnel's network-interface byte counters (64-bit).

NOTE: this only becomes visible once IPSec actually CONNECTS. If your IPSec
still fails to connect, that's the separate server-certificate-trust item being
fixed on the gateway — this build only adds the counter, it doesn't change
whether IPSec connects.

HOW TO TEST (once IPSec connects)
- Connect over IPSec, generate some traffic (load a page / speed test).
- Confirm the Connect screen shows non-zero download/upload + a live speed
  graph for IPSec (like it does for WireGuard).

REGRESSION CHECK
- WireGuard / AmneziaWG / OpenVPN traffic counters unchanged.
- Connect/disconnect, pools, deleting connections behave as before.
