v1.1.5.67 (build 163) — tvOS: reliable connection switching + import switches the live
tunnel.

- Switching back and forth between connections/pools was unreliable. Cause: rapid
  switches launched overlapping connect/disconnect operations that raced on the single
  VPN profile. Fix: all tunnel operations (connect / disconnect / pool / rotate) are
  now serialized — they run strictly one after another, so a switch always completes
  cleanly before the next starts.
- Importing a pool/config while already connected now switches the live tunnel to the
  just-imported one (and the Connect screen updates) instead of only selecting it.

HOW TO TEST: connect → switch between a pool and a server config a few times in a row
→ each switch should land reliably. Import a pool while connected → it should become
the active connection and show on Connect.
