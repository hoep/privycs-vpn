v1.1.5.18 (build 114) — tvOS: Privycs design system, smaller fonts, focus-safe, new icon.

- Applies the iPhone/iPad design system to Apple TV: teal #00CDAB on the dark
  command-console background (#070B0E) with card surfaces — instead of plain
  default styling.
- Much smaller, explicit font sizes (the default tvOS fonts were huge).
- Focus-safe layout: the Connect control takes default focus so the remote always
  lands on something actionable; vertical scroll with a horizontal server picker.
- Live traffic cards (Download/Upload + speed + sparkline) shown when connected.
- New app icon: the Privycs logo centered on a turquoise field (+ top shelf).
