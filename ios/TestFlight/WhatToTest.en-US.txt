v1.1.5.58 (build 154) — tvOS: fix Geo-Nearest pool picking + Activate-button skin.

FIX (Geo pool picked the wrong server, e.g. LAX from Austria): the rotation engine
was being given an EMPTY user country, so Geo-Nearest fell back to a random member.
The Apple TV now detects your country (public IP → the bundled on-device MMDB, same
as the phone) and passes it to the picker, so a Geo pool now picks a nearby server.
(The MMDB was already bundled via PrivycsCore; the country just wasn't being used.)

FIX: the "Activate pool" button in pool config was skinned inconsistently (full-width
block). It now matches the Connect button — centered, content-sized, teal icon+label.

HOW TO TEST: set a pool's policy to Geo, connect from your region → it should pick a
nearby server (not a far-away one). Open a pool's gear → the Activate button should
look like the rest of the app and be fully visible.
