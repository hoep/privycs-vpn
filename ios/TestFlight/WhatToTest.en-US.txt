v1.1.5.6 (build 102) — widget protocol switch actually switches now.

build 101 logged "started OK" but nothing changed: starting a manager that's
already connected (or while the old VPN is still up) is a no-op. The widget now
mirrors the app's switch fully: STOP the currently-active tunnel (IPSec + any PTP
manager) and WAIT for teardown, THEN reconfigure + start the new protocol (with
reload/retry). So the active protocol really changes.

  Tap WireGuard / IPSec → switches to those. Verify in Settings ▸ VPN + the app.
- If it still doesn't switch: send the "widget switch[" log lines — they now log
  pre/post connection status + each start attempt.
