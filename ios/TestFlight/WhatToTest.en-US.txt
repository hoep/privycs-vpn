v1.1.5.44 (build 140) — tvOS: full i18n + DNS presets + Tunnel Health.

Addresses the "half German / half English" report and missing Settings options:

- i18n is now complete and consistent. Every tvOS string is translated into all 6
  languages (en/de/es/fr/it/pt) — the earlier mix was caused by newer strings that
  weren't yet in the catalog. Added an in-app Language picker (Settings →
  Appearance) that switches language immediately, no relaunch — same as the phone
  app.
- DNS: predefined resolver presets are back (Cloudflare, Google, Quad9, AdGuard,
  Mullvad, …) via a picker, alongside the free-text field.
- Tunnel Health: the monitoring option is in Settings now — mode (Auto / Always on
  / Off), ping target, check interval, mark-dead threshold. "Off" hides the health
  pill on Connect.

HOW TO TEST (Apple TV):
1. Whole UI should now be in ONE language (your TV's language). Try Settings →
   Appearance → Language to switch on the fly.
2. Settings → DNS preset picker, and the Tunnel Health section.
3. Send a screenshot if anything still shows the wrong language.

(Backup/Restore and manual config import without the gateway are coming next — they
need a tvOS-specific transport since Apple TV has no Files app / document picker;
I've asked which approach you want.)
