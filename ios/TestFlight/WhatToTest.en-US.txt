v1.1.5.26 (build 122) — tvOS WireGuard: complete the tvOS patch (no-internet attempt).

Yes, the VPN code IS included on Apple TV — the WireGuard/AmneziaWG bridge is
compiled + active (your handshake confirmed the tunnel comes up). The "connected
but no internet" is a data-plane issue. Found a gap: the CI patch that ports
WireGuardKit to tvOS only patched the FIRST iOS guard per file, leaving
WireGuardAdapter's two wgDisableSomeRoamingForBrokenMobileSemantics() calls
iOS-only — so on tvOS that endpoint-pinning isn't applied, which can let the data
path break after the handshake. This build patches ALL guards for tvOS.

HONEST: this is a plausible fix, not a sure one. If WireGuard still connects but
passes no traffic, the cause is the libwg-go data plane on tvOS hardware (never
device-verified) and I'll need a device log to go further.
