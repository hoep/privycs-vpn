v1.1.5.66 (build 162) — tvOS: clean tunnel switch + "Round Robin" label.

- Switching configs/pools while already connected was glitchy and only worked
  properly after a manual disconnect + reconnect. Cause: a new config was started on
  the still-connected VPN profile, which flaps. Fix: the app now tears the live tunnel
  down cleanly (and disarms on-demand so it doesn't auto-reconnect) BEFORE starting the
  new one — mirroring the manual disconnect→connect that worked.
- The Round-Robin pool policy is now labelled "Round Robin" in all languages (it's a
  technical term; was "Reihum" in German).

HOW TO TEST: connected to a pool/config → pick a different one (or import + connect a
pool) → it should switch cleanly without needing a manual disconnect first.
