On-Demand / Network Rules — two important fixes in this build:

1. LOCATION PROMPT: on first launch (or when you open On-Demand & Network
   Rules) the app now asks for Location permission. Please ALLOW it — iOS only
   reveals the current Wi-Fi SSID once location is granted, and without it
   SSID rules can never match. Check it now appears under Settings > Privacy >
   Location Services.

2. RULE ORDER (priority): the TOP rule must win. Set, e.g.:
     - top:    Wi-Fi SSID = <your network>  ->  Disconnect
     - bottom: Any                          ->  Connect (always on)
   On that Wi-Fi the VPN must stay OFF (top rule wins); on any other network it
   must be ON. Reorder the rules and confirm the order is respected.

Also please verify:
- The network/state indicator no longer flaps when idle.
- Connect screen shows the right status; traffic counters move when connected.
- Pause lets traffic flow (no kill-switch block).
