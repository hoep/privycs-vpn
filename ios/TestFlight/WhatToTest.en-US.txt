v1.1.5.68 (build 164) — tvOS: Connect screen matches the active connection type +
Always-on survives switches.

- Connecting a normal (single) connection now clears any previous pool state, so the
  Connect screen shows the plain view (no stale pool/rotation card). Connecting a pool
  shows the pool card with the current server + rotation. Switching between them now
  always shows the right screen.
- Always-on (auto-connect): a disconnect→connect switch re-arms the on-demand rule
  when Always-on is enabled (the internal teardown only disarms it momentarily to stop
  the old tunnel; the new connection re-enables it).

HOW TO TEST: connect a pool → Connect shows the pool card; switch to a server config →
shows the plain connect screen; back to the pool → pool card again. With Always-on on,
switch a few times → it stays armed.
