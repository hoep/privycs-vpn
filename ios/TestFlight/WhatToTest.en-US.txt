v1.1.3.5 (build 78) — VPN pools, ZIP import, and the Smart Decision Engine.

Please focus testing on these recently-fixed areas:

1. VPN POOLS — IMPORT
   • Add tab → "Create a VPN pool" → pick a provider .zip (or several
     .conf/.ovpn/.sswan files) → name it → Save.
   • Save must respond IMMEDIATELY (it used to hang forever on some archives).
   • Confirm the pool appears with the right server count; country flags may
     fill in a moment later (geolocation runs in the background now).

2. VPN POOLS — DELETE
   • On the Configs screen, SWIPE LEFT on a pool row → Delete. (iOS had no way
     to delete a pool before.) Confirm it disappears and stays gone.

3. POOL-ONLY CONNECT
   • With ONLY a pool configured (no single connection), tap Connect. It must
     connect (pick a pool member) and prompt for VPN permission on first use.

4. SMART DECISION ENGINE (Settings → Automatic protocol selection ON)
   • After connecting, the "what the engine decided & why" panel should show
     readable lines like "Connected via WireGuard" + a reason such as
     "Austria — not a monitored country; a fast protocol is fine".
   • In an open (non-monitored) country WireGuard is preferred; AmneziaWG is
     only chosen if the connection has no WireGuard profile or WireGuard
     recently failed on this network.

5. GENERAL
   • Connect/disconnect over WireGuard, AmneziaWG, OpenVPN and IPSec.
   • On older devices (iOS 15 / older iPads): adding pools, the Save/Cancel
     buttons, and the file picker should all work.
