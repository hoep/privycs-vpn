v1.1.5.28 (build 124) — tvOS: Connect disc reachable + server/endpoint on cards.

- FIX: the Connect disc was skipped by the remote (its center column wasn't a focus
  section between the top bar and the server row). It's now a focus section, so the
  remote lands on the disc — you can connect/disconnect again.
- Server cards now show the server/endpoint identifier (small, monospaced) at the
  bottom, so duplicate-named cards are distinguishable.
- (Settings already have toggles for Kill Switch + anonymous crash reports.)

HOW TO TEST (Apple TV)
- Navigate to the Connect disc with the remote and press to connect/disconnect.
- Each server card shows its server id at the bottom. Open Settings → Kill Switch
  and crash reports are toggles.
