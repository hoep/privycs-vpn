v1.1.3.23 (build 90) — cleanup when you delete a connection.

Deleting a connection (or removing its last protocol config) now also removes
the matching VPN profile from iOS Settings ▸ VPN instead of leaving it behind,
and the home-screen widget no longer keeps showing a connection you deleted.

HOW TO TEST
- Add a connection, then delete it → it disappears from iOS Settings ▸ VPN too.
- In a multi-protocol connection, remove configs one by one; when the last one
  goes, the OS VPN profile is gone as well (not orphaned).
- Delete the connection shown in the widget → the widget updates, no stale name.

REGRESSION CHECK
- Connect/disconnect, IPSec single-VPN + traffic counter, WG/AWG/OVPN, pools,
  on-demand rules.
