v1.1.5.52 (build 148) — tvOS: fix pool/connection delete + configure pools.

FIX: the trash icon on imported connections and pools did nothing — it was a button
nested inside the row's select-button, which tvOS can't focus. Select / configure /
delete are now SEPARATE focusable buttons on each row, so delete works.

NEW — configure a pool on the Apple TV (parity with the phone): each pool row has a
gear button → pool settings:
- Selection policy (Geo / Random / Round-robin)
- Auto-rotate interval (Off / 5 min / 15 min / 1 h / 4 h / Daily)
- DNS override
- Per-server management: mark a server "Use" (active) or delete it.
Edits persist through the shared engine, so rotation honours them.

HOW TO TEST (Apple TV → Configs):
1. Trash a pool / imported connection → it disappears (delete works now).
2. Tap the gear on a pool → change rotation interval / policy / DNS, use/delete a
   server → reconnect the pool and confirm rotation follows the new interval.
