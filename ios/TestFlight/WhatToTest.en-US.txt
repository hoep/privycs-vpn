v1.1.5.19 (build 115) — tvOS device-code linking now works ("Link a TV").

Root cause found: the device-code API (start/poll) IS live + working on the
gateway host, but the TV client called www.privycs.com, whose nginx returns 405
for /api/v1/tv/*. Pointed the TV's enrollment base at gateway.privycs.com (verified
200 with a real user code). The phone link page (app.privycs.com/link) comes back
in the response and is live. So "Link a TV" no longer needs the manual fallback.

Includes build 114: tvOS Privycs design system (teal/dark), smaller fonts,
focus-safe layout (Connect takes default focus), new logo-on-turquoise icon.

HOW TO TEST (Apple TV)
- Fresh launch (or Unlink) → enrollment screen shows a code + "go to
  app.privycs.com/link". On your phone (logged in) open that, enter the code →
  the TV links itself and pulls your servers. No typing the gateway URL/token.
- Then: pick a server → Connect → status hero + live traffic.
