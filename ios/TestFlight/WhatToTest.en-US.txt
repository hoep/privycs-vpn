v1.1.5 (build 96) — security & stability hardening.

Main change: the home-screen widget no longer stores VPN config (which can
include private keys) in unencrypted shared storage — it now reads the config
from the Keychain at protocol-switch time. Plus a double-tap-connect guard and
an OpenVPN connect timeout.

HOW TO TEST
- Widget protocol switch STILL WORKS: from the widget, switch between protocols
  of a connection → it connects with the right protocol (now sourced from the
  Keychain).
- Double-tap Connect rapidly → only one connection attempt, no flapping.
- OpenVPN: connect to a reachable + an unreachable server → unreachable fails
  cleanly within ~20s instead of hanging.

REGRESSION CHECK
- Connect/disconnect all protocols, IPSec counter, single-active-VPN, pools,
  in-app language, delete cleanup, widget icons.
