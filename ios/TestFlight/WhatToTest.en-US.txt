v1.1.5.51 / iOS 1.1.5.35 (build 147) — fix "Invalid pool data" + upload files to Apple TV.

FIX: sending a pool from the iPhone failed with "Invalid pool data" — the large pool
JSON was getting mangled in url-encoding. All app→TV payloads are now base64-wrapped,
so configs/pools/backups arrive byte-exact.

NEW — upload a file to the Apple TV (no gateway), via the built-in mini-server:
- In the Privycs app: Settings → Backup → Send to Apple TV → "A file (.zip / .conf /
  .ovpn / .sswan)" → pick a file → send.
- In any browser (scan the TV's QR): an "Upload file" button takes the same files.
The TV routes by type: .zip → a pool (rotation engine), .conf → a connection.
(.ovpn / .sswan are accepted but reported unsupported — tvOS runs WireGuard/AmneziaWG.)

HOW TO TEST:
1. iPhone → Send to Apple TV → "A pool" → send → it should import (no more error) and
   appear under POOLS on the TV.
2. iPhone → Send to Apple TV → "A file" → pick a .zip of .conf files → TV shows a pool.
3. Browser → scan TV QR → Upload file → same.
