v1.1.5.4 (build 100) — widget protocol switch now works (via the app).

The widget extension cannot reliably start a packet-tunnel itself — every
in-widget attempt failed with "configuration type is wrong" (confirmed by the
device log). So tapping a protocol pill now records the request and opens the
app, which performs the switch through its proven in-app path (the same code as
tapping a protocol pill inside the app). IPSec pills already opened the app, so
all pills now behave consistently.

HOW TO TEST
- From the widget, tap a protocol pill (e.g. WireGuard on a connection that has
  WG + IPSec) → the app opens and switches to that protocol; the tunnel comes up
  on the chosen protocol.
- Tap the IPSec pill → switches back to IPSec.

REGRESSION CHECK
- Widget connect/disconnect disc still works in place; IPSec VPN-IP (private
  only); OpenVPN counter/info; WG/AWG; in-app protocol pills.
