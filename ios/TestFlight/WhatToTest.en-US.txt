v1.1.5.24 (build 120) — tvOS: fix focus/navigation + recognizable buttons.

build 119 trapped focus on the Refresh button and showed an unlabeled green gear.
- Removed the manual focus management (.focusScope/.prefersDefaultFocus) that broke
  tvOS navigation — focus now moves naturally by layout again.
- The top-right "Settings" gear and the "Refresh" button are now LABELED (icon +
  text) and use no forced colour, so they're recognizable and readable when
  focused (no more teal-on-teal blob).

HOW TO TEST (Apple TV)
- Navigate freely with the remote: disc, server cards, Refresh, Settings — focus
  moves between all of them, nothing traps.
- Top-right "Settings" opens the settings screen (DNS, kill switch, unlink, …).
