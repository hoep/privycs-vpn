v1.1.5.65 (build 161) — tvOS: fix slow connect after switching between pool/configs
(single VPN profile).

Bug: import a pool → connect → disconnect → connect a gateway/server config → very
slow. Cause: the TV created a separate VPN profile (NETunnelProviderManager) per
connection name — every pool and every gateway config got its own. They piled up, and
the system got slow reconciling many profiles / on-demand rules and stalled starting a
new tunnel while another was tearing down (a race).

Fix: the Apple TV now reuses ONE VPN profile and reconfigures it for whatever you
connect, and removes any extra leftover profiles. Switching between a pool and a
server config is now fast.

HOW TO TEST: import a 2nd pool → connect → disconnect → connect a server config → it
should come up quickly now (no long delay).
