v1.1.5.60 (build 156) — tvOS: Theme=System now reverts correctly.

Bug: device appearance = Light; set Theme=Dark, then back to System → it stayed Dark.
Cause: tvOS's .preferredColorScheme(nil) doesn't reset the window's
overrideUserInterfaceStyle back to .unspecified. Fix: the app now sets the UIWindow
override directly (System = .unspecified → follows the TV, Dark = .dark, Light =
.light), applied on launch and on every Theme change.

HOW TO TEST: with the TV in Light, set Settings → Theme → Dark (UI goes dark), then
Theme → System → it should go back to Light (the TV's appearance). And vice-versa.
