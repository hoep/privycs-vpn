v1.1.3.25 (build 91) — IPSec traffic counter on IPSec→IPSec switch.

The IPSec traffic counter previously only worked when you connected IPSec coming
from another protocol. Switching directly from one IPSec profile to another left
it stuck at 0 (the tunnel reused the same network interface, so nothing looked
"new"). It now also picks up the live IPSec interface on a profile-to-profile
switch, so the counter climbs every time.

HOW TO TEST
- Connect IPSec profile A → counter climbs. Switch directly to IPSec profile B →
  counter should climb too (not stay at 0).
- WireGuard → IPSec and IPSec → WireGuard → IPSec still work as before.

REGRESSION CHECK
- Single active VPN (no two tunnels at once), WG/AWG/OVPN counters, pools,
  delete cleanup.
