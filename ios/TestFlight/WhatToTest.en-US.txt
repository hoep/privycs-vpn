v1.1.5.56 (build 152) — tvOS: pool-config / import sheets now match the app's skin.

The pool-config (gear) and import dialogs are presented as sheets and only had a flat
gradient — they were missing the teal glow, the accent tint, and (the visible part)
the Theme color-scheme, so with Light/Dark forced they rendered in the device scheme
and looked "skinned differently". Both sheets now use the same screen chrome as the
rest of the app (gradient + glow + tint + the selected Theme).

HOW TO TEST: set Settings → Theme (Dark/Light), open a pool's gear and the import
dialog — they should match the main screens' look in both themes.
