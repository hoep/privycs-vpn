v1.1.5.1 (build 97) — fixes from device testing.

1) WIDGET PROTOCOL PILLS now switch again. The v1.1.5 security fix moved the
   widget's config read to the Keychain, but the widget lacked the Keychain
   entitlement, so the pills did nothing. The entitlement is now granted.
2) OPENVPN now shows traffic + connection info (it showed none before): the
   rx/tx counter, the connected server, the VPN IP, and the endpoint.
3) IPSEC now shows the connected server + VPN IP + endpoint on the Connect
   screen (the traffic counter already worked). ("Last handshake" stays blank —
   IKEv2 has no handshake metric.)

HOW TO TEST
- From the home-screen widget, tap a protocol pill → it switches to that protocol.
- Connect OpenVPN → Connect screen shows server next to the flag, VPN IP,
  Endpoint, and a climbing traffic counter.
- Connect IPSec → Connect screen shows server, VPN IP, Endpoint; counter climbs.

REGRESSION CHECK
- WG/AWG info + counters unchanged; double-tap guard; single-active-VPN; pools.
