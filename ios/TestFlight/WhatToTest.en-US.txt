v1.1.5.101 — Connect screen now shows the protocol pill even when a connection
has only one protocol (e.g. a WireGuard-only setup) — matching Android/Desktop.
Previously the pill row only appeared for multi-protocol connections, so iPhone/
iPad users with only WireGuard saw no protocol pill. Please check the Connect
screen shows the WireGuard (or other) pill for a single-protocol connection.

- KILL SWITCH is now a real OS-level block: with it ON, all traffic is forced
  through the tunnel and the system DROPS any traffic when the tunnel is down or
  while it is (re)connecting — nothing leaks outside the VPN. Your local network
  (LAN/printers/AirPlay) stays reachable.
- Cross-platform BACKUP now round-trips correctly with Android/Desktop: the
  "last connected" time and the active protocol are written in the shared format,
  so a backup exported on iOS restores on Android (and vice-versa) without errors
  or lost fields.

HOW TO TEST:
1) Settings → turn Kill Switch ON → connect → on a working tunnel browsing works
   and the LAN is reachable. Now force a drop (toggle airplane mode briefly /
   kill signal): traffic should be BLOCKED until the tunnel re-establishes — no
   leak to the open network.
2) Settings → Export backup on iOS → import it on the Android/Desktop app: all
   connections, the active protocol and timestamps come across intact.
