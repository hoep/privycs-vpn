STILL TO VERIFY (shipped in build 169, untested on device)
- BACKUP/RESTORE: a backup written on Android or Desktop used to restore on iOS
  as factory settings — every preference was silently lost. Each value now falls
  back on its own, and Connect-on-Demand, onboarding state and "keep monitor
  alive" are carried through in both directions.
- PROTOCOL PILLS: tapping a protocol that has only ONE config switches to it
  immediately. With several configs the picker opens and lists only that
  protocol's configs, not every config of the connection.
- POOL ROTATION: the next server is probed before the switch. A dead entry is
  skipped and marked, and your current tunnel stays up instead of being torn
  down into a failed connect. The same check runs before the first connect of a
  pool.
- POOL ROUND-ROBIN rotates across REGIONS (Europe → North America → …) with its
  own position per region. Geo-nearest uses the same region table as Android, so
  both platforms pick from the same buckets.
- NETWORK RULES: after a rule disconnects the VPN on a trusted network, a
  5-second hold prevents an immediate reconnect while Wi-Fi settles.

HOW TO TEST
1) Android → iOS backup: export a backup on Android (or Desktop), import it
   here, then check Settings — DNS, gateway URL, theme, auto-tunnel and the
   tunnel-health values must all match, not read as factory defaults.
2) A connection with a single WireGuard config: tap the WireGuard pill on the
   Connect screen — it should switch straight away. Add a second WireGuard
   config, tap again: the picker opens and shows only the WireGuard entries.
3) Pool with rotation: set a short interval and let it rotate a few times. It
   should move between regions rather than staying in one, and an unreachable
   member should be skipped without dropping the connection you have.
4) Network rule "no VPN" on your home Wi-Fi: after it disconnects, the app must
   not immediately reconnect.

ON APPLE TV
The same build ships for tvOS. The pool changes above apply there too — rotation
probes the next server before switching, and round-robin moves across regions.
Steps 1 and 4 are iPhone/iPad only (no backup import and no Wi-Fi rules on tvOS).
