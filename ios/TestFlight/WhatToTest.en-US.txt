v1.1.5.30 (build 126) — tvOS: Connect disc reachable + button contrast + opaque settings.

THE connect fix: the disc is no longer .disabled (that made it unfocusable on tvOS
when no server was resolved) and now takes DEFAULT FOCUS via focusScope — the remote
starts on it; press to connect. Combined with the .card focusable style.

- Top-bar Refresh/Settings: removed the app-wide text-colour override + the forced
  white that caused white-on-white when focused. borderedProminent now does the
  correct INVERSE itself (white text on teal unfocused, dark text on white focused).
- Settings screen is now OPAQUE (was see-through to the connect screen) and uses a
  standard Form with native toggles.

HOW TO TEST (Apple TV)
- On launch the Connect disc is focused → press to connect (finally testable!).
- Focused Refresh/Settings buttons are readable (dark text on white). Settings is
  opaque. Then: connect WireGuard → internet? (kill switch is off by default).
