v1.1.5.21 (build 117) — tvOS enroll: the link code auto-rotates (no more "expired").

The device-code expires after ~10 min; if you waited you saw "this code has
expired". The enroll screen now fetches a FRESH code ~15s before expiry (and
immediately if the server ever reports expired), so a valid code + QR is always on
screen and the link keeps working no matter how long the TV sits there.

HOW TO TEST (Apple TV)
- Leave the enroll screen open well past 10 minutes → the code/QR refreshes itself
  instead of erroring; linking still works.
- (Plus build 116: QR enroll, light/dark from Settings, Privycs colors, traffic
  counters when connected.)
