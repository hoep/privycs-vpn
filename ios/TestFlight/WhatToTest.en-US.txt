v1.1.5.59 (build 155) — tvOS: config-switch reconnect, Theme=System fix, endpoint
flags, "VPN" tab.

- Switching config while connected now reconnects with the new one: picking a
  different connection / pool / gateway config in the VPN tab re-establishes the
  tunnel with that config (only if a tunnel was already up).
- Theme → System now actually reverts to the TV's appearance (switching back from
  Dark/Light didn't take on tvOS; the view tree now re-renders cleanly on theme
  change). The Language picker keeps its "System" (follow device) option.
- Country flag of the exit point is shown: on the Connect details "Endpoint" row and
  in the pool card's current-server line (resolved on-device via the bundled MMDB).
- The "Configs" tab is renamed "VPN" (all languages).

HOW TO TEST:
1. Connected → open VPN tab → tap a different config/pool → it reconnects to it.
2. Settings → Theme → System after using Dark/Light → follows the TV appearance.
3. Connect → the Endpoint row + pool current-server show the country flag.
